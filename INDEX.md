# INDEX — map of this store

Every file by path, so a connected AI can navigate straight to what it needs instead of
relying on search. Regenerated from the repository on every push — add a file and it
appears here on its own; there is nothing to remember. Folders with more than 40 files
get an index of their own, and the row for such a folder links to it.

## Root
- [`README.md`](README.md) — what this world is.
- [`AGENTS.md`](AGENTS.md) — how a connected AI should read, converse, and update this world.
- [`sensitivity-preferences.md`](sensitivity-preferences.md) — how I want sensitive things handled.

## about-me/
- [`about-me/guide.md`](about-me/guide.md) — my chosen guide and the person behind it.

- [`about-me/deck.md`](about-me/deck.md) — the deck: eight piles of questions my AI can deal me.
